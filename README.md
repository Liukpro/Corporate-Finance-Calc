# Corporate Finance Calc

A Python-based financial analysis system that transforms raw financial statements
into structured, validated, and readable outputs — including cash flows, valuation,
and analyst-ready insights.

Designed to automate core junior analyst workflows in consulting, audit, and financial advisory.

---

## Current Version (Demo)

The current version is a **Streamlit demo** built to test and showcase financial formulas.

**Live demo:** https://corporate-finance-calc.streamlit.app

### Features

**Cash Flow**
- FCCNOGC, RO-L, FCGC, FCID, FCFR, FCRf, FCU, FCE, Change in Liquidity

**Valuation**
- Net Present Value (NPV)
- Zero Coupon Bond valuation

The demo allows flexible input for testing purposes, but this behaviour will be removed
in the production version in favour of strict, validated inputs and imports.

> Streamlit is used only for testing and visibility — not as core logic.

---

## Why this project

In real workflows, analysts spend significant time:
- cleaning financial data  
- checking consistency  
- moving data between tools  

This project automates that process and produces structured outputs.

---

## Project Goal

The final system will:

1. Read real financial statements (Excel)  
2. Clean and standardise data  
3. Apply consistent financial logic  
4. Compute analysis and valuation  
5. Output readable results (dashboard or report)
